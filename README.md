# 🎨 Art Deck - Коллекционирование Цифровых Карт Искусства

**Art Deck** — это интерактивное веб-приложение для коллекционирования и управления цифровыми карточками с произведениями искусства. Система включает механики карточных игр, управление колодами, рейтинговую систему и админ-панель для управления карточками.

---

## 🚀 Основные Возможности

### 👤 Для Обычных Пользователей

#### 📚 Коллекция Карт
- ✅ Просмотр всех имеющихся карт
- ✅ Фильтрация по редкости (8 уровней: Common → Immortal)
- ✅ Подробная информация о каждой карте:
  - Название, художник, год создания
  - Описание произведения
  - Изображение
  - 4 философских параметра (0-10):
    - 💓 **Резонанс** - эмоциональное воздействие
    - 🎯 **Виртуозность** - техническое мастерство
    - 🧠 **Глубина** - интеллектуальная сложность
    - ⚖️ **Гармония** - композиционный баланс

#### 🎯 Система Колод (Deckbuilding)
- ✅ Создание множественных колод (максимум **10 колод**)
- ✅ Максимум **60 карт в колоде**
- ✅ Одна карта может быть в разных колодах
- ✅ Редактирование, дублирование, удаление колод
- ✅ Переключение активной колоды (влияет на рейтинг)
- ✅ Выбор цвета для каждой колоды

#### 💎 Магазин Паков
- ✅ 4 типа паков с разными ценами:
  - 🌟 Starter Pack (100 монет, 5 карт)
  - 🎯 Standard Pack (250 монет, 10 карт, 1 редкая гарантирована)
  - 💎 Premium Pack (500 монет, 15 карт)
  - 👑 Ultimate Pack (1000 монет, 20 карт, легендарная гарантирована)
- ✅ Ежедневное бесплатное открытие пака:
  - **1 пак в день** (обновляется в 00:00 UTC)
  - **+50 монет** за открытие
- ✅ Бонусы за новые карты:
  - **+10 монет** за каждую новую карту в коллекции
- ✅ Анимация открытия паков

#### 🏆 Система Рейтинга
- ✅ Рейтинг рассчитывается по **активной колоде**
- ✅ Формула: `(Уникальность + Сила) × (1 + Бонусы)`
- ✅ Компоненты рейтинга:
  - **Уникальность** - разнообразие карт в колоде
  - **Сила** - сумма параметров карт с учётом редкости
  - **Бонусы**:
    - Эра (+5% за каждый век, макс +50%)
    - Художники (+10% за каждого с 2+ карты, макс +60%)
    - Редкости (+10% за каждый тип, макс +80%)
- ✅ 7 тиров: Common → Uncommon → Rare → Epic → Ancient → Legendary → Immortal

#### 🎁 Система Миссий (Quests)
- ✅ 5 основных миссий:
  1. 🎯 **Первые шаги** - открыть первый пак (+100 монет)
  2. 🎯 **Начинающий коллекционер** - 5 уникальных карт (+150 монет)
  3. 🎯 **Коллекционер** - 10 уникальных карт (+200 монет)
  4. 🎯 **Легенда** - первая легендарная карта (+250 монет)
  5. 🎯 **Мастер редкостей** - 5+ редких карт (+300 монет)
- ✅ Автоматическая проверка выполнения
- ✅ Награды при завершении

#### 👤 Профиль
- ✅ Информация пользователя
- ✅ Рейтинг активной колоды
- ✅ Разложение рейтинга по компонентам
- ✅ Статистика коллекции

#### 🏆 Глобальный Рейтинг (Leaderboard)
- ✅ Топ игроков по рейтингу
- ✅ Позиция пользователя
- ✅ Обновление в реальном времени

## 📊 Структура Firestore

### Коллекция `users`

```javascript
users/{uid}/
{
  // Базовая информация
  email: "user@example.com",
  username: "username",
  isAdmin: false,
  createdAt: Timestamp,

  // Валюта и награды
  currency: 100,                          // Монеты
  lastDailyReward: Timestamp,             // Последний дневной бонус
  dailyFreeOpens: 1,                      // Оставшиеся бесплатные открытия
  packsOpened: 0,                         // Всего открыто паков

  // Коллекция карт
  cards: { cardId: count, ... },          // Глобальная коллекция (все карты)
  completedQuests: ["quest_id", ...],     // Завершённые миссии

  // Система колод
  activeDeckId: "deck_1234567890",        // Активная колода (влияет на рейтинг)
  decks: {
    "deck_1234567890": {
      id: "deck_1234567890",
      name: "Фаворит",
      description: "Моя любимая колода",
      cards: { cardId: count, ... },      // Карты в ЭТОй колоде
      rating: 156,                        // Рейтинг этой колоды
      isActive: true,                     // Активна ли
      color: "#3a8d8e",                  // Цвет
      createdAt: Timestamp
    }
  }
}
```

## 🔧 Установка и Запуск

### Предварительные требования
- Node.js 14+ (для сборки, если требуется)
- Firebase проект с включённой Authentication и Firestore
- Современный браузер

### Шаги установки

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/korotischi-a11y/art-deck-realization.git
   cd art-deck-realization
   ```

2. **Настройте Firebase**
   - Создайте проект на [Firebase Console](https://console.firebase.google.com/)
   - Включите **Authentication** (Email/Password)
   - Включите **Cloud Firestore** (Production Mode, потом добавьте правила)
   - Получите конфиг и обновите `config.js`

3. **Обновите `config.js`**
   ```javascript
   const firebaseConfig = {
     apiKey: "YOUR_API_KEY",
     authDomain: "your-project.firebaseapp.com",
     projectId: "your-project-id",
     storageBucket: "your-project.appspot.com",
     messagingSenderId: "your-sender-id",
     appId: "your-app-id"
   };
   ```

4. **Запустите локально**
   - Используйте любой локальный веб-сервер:
   ```bash
   python -m http.server 8000
   # или
   npx http-server
   ```
   - Откройте `http://localhost:8000`

5. **Развернитесь на Vercel**
   ```bash
   npm install -g vercel
   vercel
   ```

## 🔐 Firestore Правила Безопасности

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Пользователи могут читать/писать только свои документы
    match /users/{userId} {
      allow read, write: if request.auth.uid == userId;
    }
    
    // Карты читают все, создают только админы
    match /masterCards/{cardId} {
      allow read: if true;
      allow create, update, delete: if request.auth.token.admin == true;
    }
  }
}
```

## 🎮 Как Играть

### Для новых игроков
1. **Зарегистрируйтесь** - создайте аккаунт
2. **Получите стартовую колоду** - автоматически создаётся при входе
3. **Откройте паки** - используйте 100 начальных монет
4. **Собирайте карты** - каждая открытая карта добавляется в активную колоду
5. **Создавайте новые колоды** - кликните "➕ Новая" в панели колод
6. **Переключайтесь между колодами** - рейтинг обновляется автоматически
7. **Выполняйте миссии** - получайте награды
8. **Поднимайтесь в рейтинге** - улучшайте свои колоды

### Ежедневные активности
- 🎁 Одно **бесплатное открытие пака** в день
- 💰 **+50 монет** за открытие бесплатного пака
- 🏆 Попадание в **топ рейтинга**
